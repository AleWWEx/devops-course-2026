# Git в VS Code vs терминал

## Что в VS Code удобно для работы с Git

1. **Панель Source Control** (Ctrl+Shift+G): видно список изменённых файлов и иконки их статуса — не нужно помнить `git status`.
2. **Наглядные диффы**: клик по файлу открывает сравнение «до/после» с подсветкой строк, а конфликт-редактор помогает выбирать вариант кнопками «Accept Current / Incoming / Both».
3. **Быстрые действия**: staged/unstaged переключается одним кликом, commit — ввод сообщения и кнопка ✓, встроены pull, push и переключение веток без команд.

## Что удобнее делать в терминале

Interactive rebase (`git rebase -i`) — в IDE эта операция закрыта диалогами или вообще недоступна, а в терминале можно точечно переписать историю (pick, fixup, drop) и видеть каждый шаг.
