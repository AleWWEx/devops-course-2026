# Git vs SVN: сравнение

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто указатель (ref) на коммит. Создать ветку = записать один файл в `.git/refs/heads`. Операция мгновенная и не копирует код: рабочее дерево не меняется, коммиты весят мало (хранилище содержательное, дедуплицированное).

В SVN ветка — это копия всей директории проекта в хранилище (`svn copy`). Каждая такая операция создаёт серверную копию тысяч файлов, занимает место и требует похода на сервер. Поэтому в SVN ветки создают редко и «руководство боится» — часто держат одну main-ветку и работают в ней.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. SVN — централизованная система: единственный источник истины — сервер с хранилищем. Локальной «полной копии репозитория» нет — рабочая копия хранит только текущее состояние файлов, без истории и без локальных веток. Поэтому commit, update, создание ветки — всё требует связи с сервером. Локально можно лишь изменять файлы (`svn edit`), но зафиксировать изменения без сервера нельзя. В Git наоборот: у каждого разработчика полный репозиторий с историей, поэтому коммиты, ветки, merge и просмотр истории работают офлайн, а push — отдельная, синхронизирующая операция.

## 3. В каких сценариях SVN до сих пор предпочтительнее Git?

- **Legacy-проекты**: крупные системы в госсекторе, банках, промышленности, написанные много лет назад на SVN, — миграция дорогая и рискованная, поддержку продолжают в SVN.
- **Контроль доступа на уровне каталогов**: SVN умеет разрешать «этот отдел может писать только в `/branches/payments`», а Git даёт доступ целиком к репозиторию.
- **Ограничение размера и привычный централизованный контроль**: если по регламенту нельзя хранить полные копии кода у сотрудников (юридические ограничения на выгрузку исходников), централизованная модель SVN оказывается удобнее.
- **Бинарные артефакты больших объёмов**: SVN умеет efficiently хранить крупные бинарники через system «копии на сервере» (хотя Git LFS решает и это).

Итог: новые проекты стартуют на Git, SVN остаётся только в поддержке старых систем.
